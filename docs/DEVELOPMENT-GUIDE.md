# אשמורת MARKET — מדריך למפתחים

האב־טיפוס הזה הוא הפניה לחוויית המשתמש ולהתנהגות. הוא לא חנות פעילה. אפשר לבנות ממנו מחדש בכל סטאק. מבנה הקבצים כאן הוא בחירה של האב־טיפוס, לא דרישת ייצור.

## איך מריצים

```bash
npm install
npm run build
python3 -m http.server 8765
```

הכתובת דרך השרת: `http://127.0.0.1:8765/`. אפשר גם לפתוח את `index.html` ישירות. הדף טוען את `js/app.bundle.js`, לא מודול נפרד, כדי שהדפדפן לא יחסום את התוכן.

`npm run build` מרכיב את Tailwind מ־`src/app.css` אל `assets/css/app.css`, וגם בונה מחדש את `js/app.bundle.js` מתוך קבצי המקור ב־`js/`. אחרי שינוי מחלקות או סקריפטים צריך להריץ build שוב, ואז לרענן את הדף.

`npm run prepare-data` מעתיק את קובץ הקטלוג ואת התמונות, וכותב מחדש את `js/data/catalog.js`. את `js/data/commerce.js` הוא כותב רק אם הקובץ חסר, כדי שלא יידרסו מחירים שנערכו ביד.

## מה זה מדמה, ומה לא

מדמה: מחירים בשקלים, מחיר מחוק במבצע, דמי משלוח קבועים (29 ₪), הוספה לסל, שינוי כמות, הסרה, ולידציה של טופס משלוח, ומספר הזמנה מקומי.

לא קיים: תשלום, חישוב משלוח אמיתי, מלאי, הרשמה, ניוזלטר, וקטלוג של יצרן שאינו תוצרת.

ההתחברות מדומה. אין שירות חיצוני, אין SMS, אין הצפנה ואין עוגיות. הקוד הקבוע להדגמה הוא `123456`. מצב ההתחברות נשמר ב־`localStorage` במפתח `ashmoret-session` ורק עם מזהה לקוח להדגמה, שם תצוגה, סטטוס התחברות וזמן תפוגה. פרטי לקוח בדויים שנערכו במסך הפרטים נשמרים ב־`ashmoret-demo-profile`. אין שם סיסמה, מסמך או טוקן. זה לא בקרת גישה ולא אימות זהות. שיטת ההתחברות האמיתית נשארת החלטה נפרדת ליישום. הלוגיקה מבודדת ב־`js/state/session.js` כדי שאפשר יהיה להחליף אותה.

הטלפון בפוטר ובדיאלוג השירות הוא `09-7448038`.

## זהות

אשמורת MARKET והיצרן תוצרת נשארים נפרדים בכל מסך.

- הלוגו של אשמורת, הכחול והוורוד, שייכים לכרום: סרגל עליון, כותרת, כפתורים, פוטר.
- הירוק של תוצרת מופיע רק בזהות היצרן ובתמונות המוצר.
- הסיסמה שעל נכס המותג: כל מה שצריך עד הבית.
- אין לצייר לוגו חדש. הקבצים המסופקים נמצאים ב־`assets/images/brand/`.

## עברית ו־RTL

`lang="he"` ו־`dir="rtl"` על `html`. מרווחים ויישור נכתבים עם מחלקות לוגיות (`ps`, `pe`, `ms`, `me`, `text-start`). מחירים מוצגים עם `dir="ltr"` כדי שסימן השקל והספרות יישארו בסדר הנכון.

נקודות שבירה: ברירת מחדל, `md` 768, `lg` 1024, `xl` 1280.

- מתחת ל־768: גריד מוצרים בשתי עמודות. בכותרת לוגו, אייקון חיפוש, חשבון, סל ותפריט. שורת הקטגוריות נגללת. ההירו הוא תמונה מלאה ומעליה פאנל כהה עם הטקסט. שני הבאנרים התומכים זה לצד זה.
- 768–1023: שלוש עמודות. ההירו עדיין בערימה.
- 1024 ומעלה: הירו מפוצל, ארבע עמודות מוצרים, וחמש עמודות מ־1280. הכותרת דביקה והחיפוש בשורה.
- בעמוד מוצר, הוספה לסל נדבקת לתחתית המסך מתחת ל־1024.

## מסכים

הכותרת והפוטר קבועים ב־`index.html`. כל מסך נטען אל `#app`.

| נתיב | מסך |
| --- | --- |
| `#/` | דף הבית א, תוצרת |
| `#/market` | דף הבית ב, כמה יצרנים |
| `#/c/:slug` | קטגוריה |
| `#/m/:slug` | תבנית יצרן |
| `#/p/:id` | מוצר |
| `#/search?q=` | תוצאות חיפוש |
| `#/cart` | סל |
| `#/checkout` | תשלום |
| `#/order/:id` | אישור הזמנה |
| `#/login` | התחברות מדומה וקוד הדגמה |
| `#/account` | סקירת האזור האישי |
| `#/account/details` | פרטי לקוח ההדגמה, ניתנים לעריכה |
| `#/orders` | היסטוריית הזמנות קבועה להדגמה |
| `#/orders/:id` | פירוט הזמנת הדגמה |

דף הבית א, לפי הסדר: סרגל משלוח וטלפון, כותרת, תשע קטגוריות, הירו עם שני באנרים תומכים, מוצרים נבחרים, שורת פסטה, פס קידום עם אריזת הוורוד, מבצעים שאינם בנבחרים, שורת שירות אחת, פוטר. אין ניוזלטר.

דף הבית ב משתמש באותו כרום ובאותם רכיבים, עם סדר אחר: כניסה ליצרנים, כרטיסי יצרן, ומקבץ מעורב מתוך קטלוג תוצרת. רק לתוצרת יש קטלוג. `sample-a` ו־`sample-b` הם כרטיסים מסומנים כדוגמה.

עמוד היצרן הוא קובץ אחד, `js/screens/listing.js`, לפי רשומה ב־`js/data/manufacturers.js`. יצרן נוסף הוא רשומה נוספת, לא תבנית חדשה.

## רכיבים

- כותרת, חיפוש, תפריט מובייל, ניווט קטגוריות: `js/components/shell.js`
- כרטיס מוצר וגריד: `js/components/product-card.js`
- קרוסלה: `js/components/carousel.js` (Embla, `direction: "rtl"`)
- סינון ומיון: `js/components/filters.js`
- טוסט ואישור הסרה: `js/components/toast.js`
- מסכים: `js/screens/`

Embla רץ על שורות מוצרים ועל מוצרים קשורים. שורת הקטגוריות היא גלילה אופקית רגילה. ההירו הוא קומפוזיציה אחת, לא קרוסלה.

GSAP מוגבל לכניסת ההירו, לפתיחת התפריט במובייל, לטוסט, ולמשוב על הוספה לסל. `prefers-reduced-motion` מכבה את התנועה.

## נתונים

`assets/data/catalog.csv` הוא העתק של קטלוג תוצרת, בלי שדות שהומצאו. 184 מוצרים, תשע קטגוריות. `js/data/catalog.js` מחזיק שם, קטגוריה, ברקוד, משקל, יחידות במארז, עמוד בקטלוג, ונתיב תמונה. מוצר בלי צילום מתאים מסומן כ־placeholder ומוצג כ״תמונה זמנית״.

27 צילומי אריזה הותאמו למוצר לפי שם ומשקל. תמונה שלא תואמת למוצר לא הוצבה על מוצר אחר.

`js/data/commerce.js` הוא המקום היחיד למחיר, למחיר מחוק, ולדמי המשלוח. המחירים כתובים כמספרים קבועים. הם לא מחושבים מברקוד. כדי לשנות מחיר עורכים את הקובץ ומרעננים את הדף.

הסל נשמר ב־`localStorage` במפתח `ashmoret-cart` כמזהי מוצר וכמויות. הסכום נקרא מ־`commerce.js` בכל שינוי. הזמנות הדגמה נשמרות ב־`ashmoret-orders`.

## קנייה

אפשר להוסיף מהכרטיס או מעמוד המוצר, לשנות כמות, ולהסיר אחרי אישור. הסכום בסל כולל את דמי ההדגמה.

בקופה חובה שם, טלפון ישראלי, עיר, רחוב ומספר בית. שדה ריק מציג שגיאה בעברית. אזור ״תשלום וזיהוי לקוח״ ריק בכוונה: אופן הזיהוי ואמצעי התשלום עדיין לא הוחלטו, והעמוד לא נועל שיטה.

שליחה יוצרת אישור עם מספר הזמנה. המסך אומר במפורש שלא בוצע תשלום, שלא חושב משלוח אמיתי, ושלא נפתחה הזמנה במערכת.

## החלטות פתוחות

- ההתחברות, הקוד והאזור האישי הם הדגמה בלבד. אין הרשמה. הקנייה לא תלויה בהתחברות. שיטת הזיהוי בייצור עדיין לא הוחלטה.
- אמצעי תשלום וזיהוי לקוח בקופה לא נבחרו.
- מחירים, משלוח, מלאי, והיצרנים שאינם תוצרת הם הדגמה.
- מספר הטלפון בכרום הוא מציין מקום.
